# Welcome to sorting algorithm
I built this algorithm using the explanations of Bhargava on the book ***Grokking Algorithms: Second Edition***.

The structure is really simple with two functions.

## findSmallest
- Finds the smallest number on a given array .
- Returns it's index.

## selectionSort
- Creates a new array with type slice.
- Creates a for loop to sort the old array, creating a new one.

## main
- Prints the new array on the screen.

Feel free to clone this and practice on your own.
