# Welcome to sorting algorithm
I built this algorithm using the explanations of Bhargava on the book ***Grokking Algorithms: Second Edition***.

The structure is really simple with two functions.

## findSmallest
- Finds the smallest number on a given array.
- Returns its index.

## selectionSort
- Creates a sorted copy of the original array.
- Uses a for loop to extract the smallest element on each iteration.

## main
- Prints the sorted array on the screen.

## Time Complexity
This algorithm runs in **O(n²)** time, meaning it checks every element 
for every position in the array.
